FAQ

Les réponses aux questions fréquentes.

Comment demander un devis ?

Utilisez le formulaire de projet. Le brief est enregistré localement et un message WhatsApp prérempli peut être envoyé au studio.

Les tarifs sont-ils fixes ?

Les tarifs de départ peuvent être affichés sur le site, mais certains projets nécessitent un devis personnalisé selon le volume, le délai et les livrables.

Quels formats sont livrés ?

Selon le projet : PNG, JPG, PDF, SVG, MP4 et autres formats nécessaires. Les modalités exactes sont définies dans le brief.

Le studio accepte-t-il les projets à distance ?

Oui. Le formulaire et WhatsApp permettent de cadrer un projet même lorsque le client n'est pas physiquement à Orodara.
